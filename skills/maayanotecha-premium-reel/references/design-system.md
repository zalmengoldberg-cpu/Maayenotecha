# מערכת עיצוב – "פרימיום אפל" למעיינותיך (לא משנים בין סרטונים)

המימוש: `template/brand/brand.css` + `brand.js`. כל פורמט (reel / books / talk / quote / חופשי) חייב להשתמש בהם – לא להגדיר מחדש צבעים, פונט או אנימציות.

| רכיב | כלל |
|---|---|
| פורמט | 1080×1920 (9:16), ‏30fps, אורך 20–26 שנ'. טקסט חיוני בין y=270 ל-y=1550 |
| רקע | **שחור**. שלושה מצבים: במה עם זרקור ורצפה מבריקה (`ap_stage.jpg`) לשוטי טלפון · סרט "זכוכית נוזלית" טורקיז-סגול-כחול בלולאה (`assets/ribbon/`, אטימות ~40%) למעיין הספרן · שחור עם זוהר כחול עדין מלמטה לסיום |
| פונט | Fb Sayeeda Book (Bold לכותרות, Light/Regular למשנה). ספרות: Philosof Black. לטינית: Heebo |
| כותרות | גדולות (86–230px), מעט מילים, גרדיאנט לבן→כסוף (`#fff → #aebfdf`), פס הברקה זז (`.gl`), צל עמוק = "צפות". כניסה: מלמטה + טשטוש שמתפוגג |
| "חדש!" | 230px, גרדיאנט טורקיז→לבן→סגול, זוהר |
| לוגואים | מעיינותיך בכסוף (`assets/logo/splash_mono.png` + `new-wordmark-white.png`); צמאה–יריד החסידות מלא (`assets/yarid/tzama_filled.png`), קטן בפינה ב-`yarid_small_mono.png`. עם הברקה (`.shn`) וצל |
| זכוכית | רק בשורת החיפוש (`.qbar.glass`) בפורמט reel. בשאר הפורמטים – בלי זכוכית |

| טלפון | iPhone בסגנון 17 Pro, טיטניום כחול כהה, צף בתלת-ממד על הבמה, מציג צילומי מסך אמיתיים |

| ספרים | כריכות תלת-ממד שקופות (`assets/covers/*.png`), צפות, השתקפות (`-webkit-box-reflect`), נדנוד עדין |

| סאונד | מוזיקה אלקטרונית-קולנועית עם פסנתר ונגיעה מזרחית; ווש+אימפקט במעברים, סחרור דפים במערבולת, קליק בלחיצות |
