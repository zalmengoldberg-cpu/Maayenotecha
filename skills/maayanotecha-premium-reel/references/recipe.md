# המתכון – מבנה הסרטון ומפת הקוד

## ציר הזמן של גרסת הבסיס (25.25 שנ', `examples/config-launch.json`)
| זמן | קטע | מה קורה | בקוד (`template/reel.html`) |
|---|---|---|---|
| 0–4.0 | **הוק – מסה** | שוט AI קולנועי (מגדל→אולם) עם "ים של ספרים." מהפריים הראשון, רחפן בכניסה, 3 פסים, רשת 12 שוטים + לוגו צמאה מלא, זום מואץ, "איך מוצאים את הספר שלך?" | `FULL` (=`CFG.hookShots`), `STRIPS`, `#fGrid`, `#fPlate`, `#hk1/#hk2`, `renderHook()` |
| 4.0–5.4 | **השקה** | מבט על האולם (מוחשך), "חדש!", "האתר של מעיינותיך", כתובת שנלחצת | `#brk`, `#brkUrl`, `#dive` |
| 5.0–6.1 | **צלילה** | שוט AI: צלילה מהאולם לחושך → טלפון על הבמה (תואם לפריים הראשון של הטלפון) | `#dive`, `footage/seg/DV_*` |
| 6.1–6.8 | טלפון | הכפתור הצף של מעיין הספרן יוצא מהמסך ונלחץ | `pops`, `#popFab`, `#scrDim` |
| 6.8–15.8 | **מעיין הספרן AI** | "פשוט כותבים למעיין ספרן הAI שלנו" → הקלדה → מערבולת → 2 ספרים; "מעיין הספרן ימצא לך ספר שמדבר אליך." מתחת לספרים | `QA` (=`CFG.qa`), `VX` (מערבולת), `#lhA/#lhB` |
| 15.8–18.3 | קטגוריות | שמות באלכסון + כריכות, שורות בכיוונים מתחלפים | `CATN` (=`CFG.categories`), `#catFlow`, `--catAngle` |
| 18.3–21.8 | **טעימה מהספר** | כפתור יוצא מהמסך → כריכה שטוחה → נפתח RTL → דפים | `#taste`, `#book`, `#flip`, `assets/taste-0*.png`, `cover_flat.jpg` |
| 21.8–25.25 | סיום | לוגו כסוף, "בית לספרות חסידית", "היכנסו ושאלו את מעיין הספרן", כתובת | `#end` |

### שני שעונים
- `renderHook(T)` עובד בזמן הסרטון.
- `renderMain(t)` עובד בזמן "פנימי" של הגרסה המקורית. `mapMain(T)` + `SEGS` (רשימת `[מ, עד, התחלה-פנימית]`) קובעים אילו קטעים פנימיים מוצגים ובאיזה סדר → **כך מסדרים מחדש / מקצרים קטעים**.
- `WARP` (בסוף הקובץ) מותח זמן (האטה) – גרסה איטית = WARP עם קטעים ארוכים יותר. כשמשנים אורך: לעדכן גם את משך המוזיקה (`finish.sh` מקבל wav) ואת זמני האפקטים.

## CONFIG – מה אפשר לשנות בלי לגעת בקוד
```jsonc
{
  "text": { "hook1","hook2"(\n=שורה חדשה),"newTag","launch","url","libA","libB","sampleTitle","sampleSub","endTag","endSub" },
  "qa": [ {"q":"שאלה","a":"","b":[["slug","שם ספר","מחבר"],...],"s":8.05,"d":1.75}, ... ],   // s = זמן פנימי, d = משך
  "categories": ["..."], "covers": ["slug",...],                                               // מערבולת/שורות
  "hookShots": [ {"k":"H1","a":0,"b":1,"pos":"50% 50%","z0":1,"z1":1.06,"sp":4.7}, ... ],      // k = קידומת פריימים ב-footage/seg
  "segFrames": {"X1":125},                                                                    // מספר פריימים לקידומת חדשה
  "variant": { "accentHue": 0, "catAngle": -12, "background": "ribbon|stage" }
}
```
שינויים שדורשים עותק של `reel.html`: סדר קטעים (`SEGS`), האטה (`WARP`), ספר אחר לטעימה (`taste-0*.png`, `cover_flat.jpg`), צילום מסך אחר לטלפון.

## איסוף תוכן אמיתי (Playwright)
- **צילומי מסך:** `devices['iPhone 15 Pro Max']`, ‏viewport 430×880, אחרי לחיצה על "אישור" בעוגיות. הכפתור הצף של הספרן: גוללים לקטגוריות.
- **שאלות לספרן:** בדף הבית לוחצים "מעיין הספרן ימצא לך ספר", ממלאים את ה-textarea, Enter, מחכים ~35 שנ', ומחלצים את `a[href^="/books/"]` מהתשובה (שם, מחבר, src של התמונה).
- **כריכות:** ‏`https://maynotechabooks.co.il/__l5e/assets-v1/.../<slug>-u618x810.png` (או מ-supabase) → `template/assets/covers/<slug>.png`.
- **טעימה מהספר:** קישור PDF מ-supabase בעמוד הספר → `pdftoppm -r 200 -png -f 1 -l 6` → `taste-01..05`. כריכה תלת-ממדית → יישור פרספקטיבה (PIL PERSPECTIVE) → `cover_flat.jpg`.
- **כריכה שטוחה לשוט "סיום טלפון":** לרנדר פריים נקי עם `renderHook(9); renderMain(6.87)`.
