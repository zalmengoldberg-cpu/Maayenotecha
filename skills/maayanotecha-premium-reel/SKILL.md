# סרטוני פרימיום – מעיינותיך (שפה גרפית אחת, הרבה סוגי תוכן)

הסקיל מורכב משני חלקים:
1. **ערכת מותג משותפת** (`template/brand/`, כולל `hooks.js` – 7 סוגי פתיחה שמתחלפים) – פונט, כותרות כסופות מבריקות, צבעי מבטא, רקעים (במה / סרט זכוכית / זוהר), לוגואים צפים, ספרים צפים עם השתקפות, מערבולת ספרים, חשיפת מילים, מסך סיום. כל פורמט נבנה ממנה, ולכן הכול נראה כמו אותו קמפיין.
2. **פורמטים מוכנים** – כל אחד הוא קובץ HTML עם ציר זמן `render(t)` שמוגדר מ-`config.json`:

| פורמט | קובץ | למה | אורך |
|---|---|---|---|
| `reel` | `template/reel.html` | פרסומת לאתר / מעיין הספרן AI / טעימה מהספר (סרטון ההשקה) | ~25 שנ' |
| `books` | `template/books.html` | הצגת ספרים חדשים: "חדש!" + מערבולת → ספר אחרי ספר (כריכה צפה, שם, מחבר, שורה) → כולם יחד → סיום | 2.4 שנ' לספר + ~8 |
| `talk` | `template/talk.html` | אדם מדבר (רב, מחבר, לקוח, ראיון): וידאו מלא או "כרטיס" צף על במה, שם ותפקיד, כתוביות מילה-מילה עם הדגשה, כריכה שקופצת כשמוזכר ספר | אורך הקטע + 3.4 |
| `quote` | `template/quote.html` | רעיון / ציטוט / משפט תוכן: טיפוגרפיה קינטית גדולה, ואז הספר שממנו זה לקוח | ~10–14 שנ' |
| חופשי | עותק של אחד מהם | רעיון שלא מתאים לפורמט – בונים מרכיבי `brand.js` (ראה references/formats.md §בניית פורמט חדש) | |

## חומרי הגלם מהיריד
`template/footage/catalog.json` – קטלוג של כל 34 הקליפים מהיריד (תיקיית "יריד" בדרייב של אסרף / מנדי בלוי): מה רואים, תגיות, ורגעים טובים. `scripts/pick_footage.py` בוחר בכל סרטון רגעים שלא שומשו (נרשמים ב-`footage/used.txt`, לשמור ולעשות commit), אפשר לפי נושא (`--theme kids|mass|crowd|reading|signage|walk`). `--hook-clip` מציע קליפ להוק מסוג footage בכל פורמט. הסרטונים עצמם לא בסקיל (4.5GB) – יורדים מהדרייב לפי הצורך.

## חובה לקרוא לפני עבודה
1. `references/lessons.md` – ההערות של הלקוח מסרטון ההשקה. מחייבות בכל פורמט.
2. `references/design-system.md` – השפה הגרפית (לא משתנה).
3. `references/formats.md` – כל פורמט: מבנה, שדות config, הכנת חומרים.
4. `references/hooks.md` – קטלוג ההוקים (7 סוגים + שוטי AI) וכלל הרוטציה: אף פעם לא אותו הוק כמו ב-3 הסרטונים האחרונים.
5. `references/variations.md` – מה לשנות כדי שהסרטון לא ייראה כמו הקודם, ויומן מה כבר נעשה.
6. `references/ai-generation.md` – הייגספילד/fal: שוטים, רקעים, מוזיקה, תמלול, בדיקת ויראליות, מחירים.
7. לפורמט `reel` גם `references/recipe.md`.

## זרימת עבודה
1. **בריף בשאלה אחת** (רק מה שחסר): סוג תוכן → פורמט · מסר אחד · חומרים (ספרים / וידאו של דובר / טקסט) · קריאה לפעולה · עם/בלי לוגו יריד.
2. **הוק**: לבחור סוג הוק לפי `hooks.md` שלא הופיע ב-3 הסרטונים האחרונים, ולהתאים טקסט/תמונה למסר. אם יש תקציב – שוט AI חדש להוק.
3. **וריאציה**: לבחור לפי `variations.md` שילוב שלא נעשה ב-`video/` ובביומן. לכתוב את הבחירה בתסריט.
4. **תסריט** לפי שניות. כל טקסט חייב לעבוד בלי סאונד.
5. **חומרים אמיתיים בלבד**: כריכות/צילומי מסך מהאתר, טקסטים ושמות כפי שנמסרו, ציטוטים מדויקים, תמלול נאמן לדובר. לא ממציאים.
6. **config.json** מתוך `examples/` (שדה `format` קובע את הקובץ).
7. **AI להקפצת רמה** (אופציונלי, להציג עלות קודם): שוט קולנועי/מעבר בהייגספילד, רקע/לולאה/מוזיקה/אפקטים ב-fal.
8. **בדיקת פריימים** → **רינדור** → **סאונד** → **גיליון בדיקה** → (בדיקת ויראליות) → `video/maayanotecha_<נושא>_<format>_9x16_vN_<yyyymmdd>.mp4` + שורה ביומן הווריאציות + commit/push.

```bash
cd skills/maayanotecha-premium-reel
cp <brand-kit>/assets/fonts/fontbit/FbSayeedaBook-*.otf <brand-kit>/assets/fonts/fontbit/FbPhilosof-Black.otf template/fonts/

(cd template && python3 -m http.server 8765 &)        # השרת רץ מתוך template/

node scripts/render.js examples/config-books-new.json frames          # האורך נקבע אוטומטית
bash scripts/finish_simple.sh frames out.mp4 [music.wav] [voice.wav]  # books/talk/quote
bash scripts/finish.sh frames out.mp4                                 # reel (אפקטים מסונכרנים)
```
