# מעיינותיך · מערכת עיצוב (שכבת הלבשה)

הסקיל הזה **לא בונה אתר**. הוא מלביש מראה על מה שהמשתמש כבר בונה איתך.
המשתמש עובד בתהליך שלו ועם האפיון שלו. התפקיד שלך הוא לבנות בדיוק את מה שהאפיון אומר, ולצבוע אותו בשפה הזאת.

## חוק הברזל: האפיון קדוש
מה **אסור** לשנות בגלל הסקיל:
- דפים, מסכים, סקשנים, השלבים בתהליך והסדר שלהם
- שדות, כפתורים, פעולות, לוגיקה, נתונים ומבנה הנתונים
- טקסטים וכותרות שהמשתמש כתב (מותר לתקן רק אם ביקש)
- טכנולוגיה שכבר נבחרה (HTML רגיל, React, Tailwind – נשארים)
- אין להוסיף סקשנים, כרטיסים, הירו, גרפים, סרגל צד או עוזר AI שלא באפיון

מה **כן** משתנה: צבע, גופן, משקלים, מרווחים, רדיוסים, צללים ועומק, זכוכית, אייקונים, מראה של רכיבים קיימים, ומצבי hover/focus/active.

אם משהו באפיון מתנגש עם המערכת (למשל האפיון מבקש כפתור אדום), **האפיון מנצח**. ממשים אותו בצורה הכי קרובה לשפה (אדום = `--bad`).
אם לא ברור אם שינוי הוא "עיצוב" או "אפיון" – לא משנים, ושואלים במשפט אחד.

## איך מלבישים (בכל בקשה)
1. **קרא את האפיון / הקוד הקיים** ורשום לעצמך את הרכיבים שבו. אל תשנה את הרשימה.
2. **הטמע את השכבה**: הרץ `python3 scripts/bundle.py` (או `--js` אם יש אייקונים/לוח שנה/גרפים) והדבק את הפלט ב-`<head>` של הארטיפקט. אם אי אפשר להריץ סקריפט – העתק את `references/tokens.css`, `references/skin.css`, `references/components.css` בתוך `<style>`.
3. **הוסף `class="mt-skin"` ל-`<body>`** (או לעטיפה הראשית). רק בזה כפתורים, שדות, טבלאות, כותרות וכרטיסים קיימים כבר מקבלים את המראה.
4. **מפה רכיבים קיימים** למחלקות לפי הטבלה למטה. אפשר להוסיף class, אבל לא לשנות היררכיה או תוכן.
5. **React + Tailwind**: אל תכתוב מחדש. הוסף את ה-`<style>` מהשלב הקודם, ו/או את `python3 scripts/bundle.py --tailwind` כ-config, והחלף רק className של צבע/רדיוס/צל.
6. **בדוק** לפי הצ'קליסט בסוף.

## מיפוי: מה שיש באפיון ← מה מלבישים
| באפיון | מחלקה / רכיב |
|---|---|
| כפתור פעולה ראשית | `btn btn-primary` (כהה) |
| פעולה בתוך כרטיס, "הוסף…" | `btn btn-brand` (כחול) |
| כפתור משני / ביטול | `btn btn-secondary` או `btn btn-ghost` |
| כפתור עם אייקון בלבד | `btn btn-secondary btn-icon` |
| טאבים / סינון תצוגה | `seg` (ו-`seg seg-brand` לניווט ראשי), כל טאב `button[aria-selected]` |
| שורת חיפוש | `search` (label עם input) |
| משתמש מחובר בכותרת | `user-chip` + `mono` |
| כרטיס / פאנל / מודול | `card` · על רקע צבעוני או תמונה: `card card-glass` · כהה: `card card-dark` |
| שורה ברשימה בתוך כרטיס | `row-tile` |
| מספר מרכזי / KPI | `card kpi` + `t-kpi` (+ `DS.spark` רק אם יש באפיון נתוני מגמה) |
| טבלה | `table` בתוך `table-wrap` |
| סטטוס | `status ok / warn / bad / info` |
| מונה התראות | `badge` (`gold` לחדש, `soft` לניטרלי) |
| אווטאר בלי תמונה | `mono` עם ראשי תיבות (`plum`, `gold`, `sage`, `kraft`) |
| פס התקדמות | `bar` עם `--v:60%` |
| סרגל צד (רק אם קיים באפיון) | `sidebar` + `sb-head`, `sb-profile`, `sb-search`, `sb-label`, `sb-item[aria-current=page]` |
| לוח שנה / תאריכים (רק אם קיים) | `<div class="hcal"></div>` + `DS.calendar(el,{events})` |
| כותרת פתיחה עם תמונה (רק אם קיימת) | `hero` + `hero-art` + `hero-copy` (+ `chip-float`) |
| עוזר / צ'אט (רק אם קיים) | `assist` |

דוגמה מלאה לכל הרכיבים יחד: `references/example-dashboard.html` (לעיון בלבד, לא תבנית להעתקה למסך שהאפיון לא מבקש).

## השפה בקיצור
- **קנבס** אפור־קריר `--canvas`, משטחים לבנים, זכוכית רק מעל צבע או תמונה.
- **צבע פעיל אחד**: כחול מלכותי `--royal`. **זהב** `--gold` פעם אחת במסך, לדבר הכי חשוב.
- **גופן** Rubik בלבד. 900 לשם חודש ולכותרת תצוגה. 400 לברכות ולמספרים גדולים. 500 לכותרות כרטיסים.
- **אותה צורה ואותו עומק**: כל הפקדים באותה שורה באותו גובה (38), רדיוס גלולה, `--elev-1`.
- **עומק**: 4 רמות (`--elev-1..4`) ושפת אור עליונה. בלי צללים כהים ובלי מסגרות עבות.
- **זכוכית**: מילוי 56%, blur 22 + saturate 160%, גבול לבן 1px, שפת אור, צל רך.
- **RTL** לכל מכל, וספרות בתוך `.num` (LTR, tabular).

## תמונות ואיורים
- ארטיפקט לא יכול לטעון קבצים חיצוניים. נכס מהסקיל מוטמע כ-data URI: `python3 scripts/bundle.py --img assets/img/hero-wellspring.webp`.
- נכסים: `assets/img/hero-wellspring.webp` (ספר זכוכית ומעיין, לבמת `hero`), `assistant-flame.webp` (לכרטיס `assist`), `silk-waves.webp` (טקסטורת `sidebar`, דרך `--silk:url(...)`), `assets/logos/` (סימן וצמד מילים), `assets/covers/` (12 כריכות אמיתיות).
- משתמשים בתמונה **רק במקום שהאפיון כבר הגדיר תמונה/באנר/כותרת עם תמונה**. לא מוסיפים איורים לקישוט.
- אם צריך איור חדש ויש חיבור ל-fal: נושא אחד, תאורת סטודיו, רקע אחיד `#D1D4DD`, ליבה בזהב `#F2911C` ושבירות בכחול `#3F5499`, השליש הימני ריק, **בלי טקסט** בתוך התמונה.
