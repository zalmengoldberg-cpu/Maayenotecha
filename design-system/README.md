# ממשק הצוות של מעיינותיך · v1.1

מערכת עיצוב לכלים הפנימיים של העובדים בלבד: אזור הניהול באתר ומערכת תהליכי העבודה. האתר הציבורי והתוכן השיווקי לא מושפעים.

| קובץ | מה יש בו |
|---|---|
| `index.html` | התיעוד: הפירוק של המקורות, עקרונות, צבע, טיפוגרפיה, עומק וזכוכית, פקדים, רכיבים חיים, איורים, אייקונים |
| `dashboard.html` | מסך דוגמה מלא: סרגל צד, הירו עם איור, KPI, לוח שנה עברי, הזמנות, עוזר |
| `tokens.css` | כל הטוקנים: צבע, טיפוגרפיה, מרווחים, רדיוסים, גבהי פקדים, 4 רמות עומק, 3 רמות זכוכית, תנועה |
| `components.css` | הרכיבים: כפתורים, טאבים, חיפוש, צ'יפ משתמש, מונוגרמות, סטטוסים, כרטיסים, KPI, טבלה, סרגל צד, לוח שנה, הירו, עוזר, גאוג', לו"ז |
| `ds.js` | אייקונים (SVG sprite), סרגל מתקפל, טאבים, לוח שנה עברי (Intl + גימטריה), ספארקליין, גאוג' |
| `assets/` | Rubik, לוגו מלא ואייקון (לרקע בהיר ולרקע כהה), כריכות, איורי fal |

## שימוש ב-Claude הרגיל (claude.ai) – סקיל
`skill/maayanotecha-staff-ui.zip` הוא סקיל שמלביש את המערכת על מסכים פנימיים לצוות, בלי לשנות את האפיון או את תהליך העבודה. בהתנגשות בין עיצוב לאפיון הוא שואל, רכיבים שלא באפיון הוא מציע בצ'אט, ורכיבים שאין במערכת הוא בונה בדומה לקיים (או שואל).
מעלים פעם אחת: claude.ai ← Settings ← Capabilities ← Skills ← Upload skill.
`skin.css` + `class="mt-skin"` על ה-body מלבישים גם HTML רגיל בלי מחלקות (כפתורים, שדות, טבלאות, כותרות, כרטיסים).

## שימוש בקוד
```html
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Rubik:wght@300;400;500;700;800;900&display=swap">
<link rel="stylesheet" href="design-system/tokens.css">
<link rel="stylesheet" href="design-system/components.css">
<script src="design-system/ds.js" defer></script>
```
לוח שנה: `DS.calendar(el, { events: { "2026-11-05": [{ t: "כותרת", s: "תיאור", time: "10:00", gold: true }] } })`

## המקורות ומה נלקח מכל אחד
- **לוח שנה עברי** – גיליון לבן עם פינות תחתונות 36px, חודש במשקל 900, אות עברית מעל מספר לועזי אפור, נקודת אירוע, עיגול ליום נבחר, פאנל יום עם "זמני היום".
- **Sidebar UI** – זכוכית כהה מעל משי, פרופיל + החלפת חשבון, חיפוש גלולה, תוויות קבוצה, פריט פעיל ברוחב מלא (כחול מלכותי + קו זהב במקום אדום), מצב מקופל. הלוגו הוא כפתור הכיווץ, ובמובייל הוא פותח את המגירה.
- **MediCore** – קנבס אפור־קריר, במה עם איור פרמיום והטקסט במרווח הריק, כפתור כהה + רפאים, כל פקדי השורה העליונה באותו גובה/רדיוס/עומק, KPI עם ספארקליין מדורג, טבלה בלי מסגרות.
- **CareNest** – כרטיס זכוכית בחמש שכבות (מילוי 56%, blur 22 + saturate 160%, גבול לבן 1px, שפת אור עליונה, צל רך), שורות פנימיות אטומות יותר, כרטיס עוזר כהה עם צילום, הצגה בפרספקטיבה.

## איורים
נוצרו ב-fal (`google/nano-banana-2.1`). העמודים טוענים את המקור ב-2K מ-fal ונופלים לתצוגה מקומית (768px) ב-`assets/img` אם אין גישה.
כדי לשמור את המקורות בריפו: `bash design-system/scripts/fetch-fal-images.sh`.
תבנית הפרומפט לאיורים חדשים נמצאת ב-`index.html#art`.
