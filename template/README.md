# תבנית רילס "פרימיום אפל" – מעיינותיך

התבנית שממנה נבנה הרילס של השקת האתר (`video/maayanotecha_reel_yarid_9x16_v15-slow_20261109.mp4`).
היא נועדה להפקת סרטונים חדשים, עם תוכן אחר, בדיוק באותו סגנון.

- **`reel_template.html`** – כל הסרטון: HTML/CSS/JS עם ציר זמן דטרמיניסטי. הפונקציה `render(t)` מציירת פריים מדויק לכל שנייה.
- **`scripts/`** – רינדור הפריימים, תמונות בדיקה וקידוד ל־MP4.
- **`assets/`** – רקעים, לוגואים בגווני הסרטון, כריכות, צילומי מסך מהאתר, טעימה מהספר, מוזיקה.
- **`fair/`** – הוראות לשחזור צילומי היריד מהדרייב. הפריימים עצמם לא נשמרים בריפו.
- **`PROMPT.md`** – פרומפט מוכן להדבקה בסשן חדש של Claude, להפקת סרטון חדש בסגנון הזה.

- **`SEGS`** קובע אילו קטעים מתוך ציר הזמן הפנימי מוצגים ובאיזה סדר.
- **`WARP`** מאט קטעים, כמו בגרסה האיטית.
- כדי לשנות אורך: עורכים את שניהם יחד עם המוזיקה.

## 3. מה מחליפים לסרטון חדש

1. **טקסטים:** `#hk1`, `#hk2`, `#brk`, `#lhA`, `#lhB`, `#tKick`, `#endTag`, `#endSub`.
2. **שאלות ותשובות** (`const QA`): שאלות אמיתיות ששואלים את מעיין הספרן באתר, וספרים מתוך התשובות האמיתיות שלו. לא ממציאים.
3. **כריכות** (`assets/covers/<slug>.png`): מורידים מהאתר (‎`__l5e/assets-v1/...-u618x810.png`).
4. **צילומי מסך:** Playwright עם `iPhone 15 Pro Max`, ‏viewport ‏430×880, אחרי לחיצה על "אישור" לעוגיות.
5. **הוק:** צילומי וידאו אחרים. מעדכנים את `fair/segs.txt` (קליפ, התחלה, אורך) ואת `FULL`.
6. **מוזיקה:** fal ‏`elevenlabs/music/v2.5` עם `composition_plan`, ואז חותכים כך שהמכות נופלות על החיתוכים (ראו PROMPT.md).

## 4. הרצה

```bash
# פעם אחת: לשים בתיקייה fonts/ את קובצי Fontbit
# FbSayeedaBook-{Light,Regular,Bold}.otf + FbPhilosof-Black.otf
# (מחבילת המותג maayanotecha-media; לא נשמרים בריפו בגלל הרישיון)
bash fair/getseg.sh                       # צילומי היריד מהדרייב (צריך גישה ל-drive.usercontent.google.com)
python3 -m http.server 8765 &             # מתוך תיקיית template
node scripts/stills.js reel_template.html preview 1.0 4.9 11.4 20.3   # בדיקת פריימים
node scripts/render.js reel_template.html frames 25.55               # כל הפריימים
bash scripts/encode.sh frames assets/music_25.55s.wav out.mp4         # MP4 + גיליון בדיקה
```

תמיד לבדוק את גיליון הבדיקה (`out_contact.png`) לפני מסירה: חיתוכים, טקסט שנחתך בקצה, הבהובים במעברים.
