# חדר הבקרה של מעיינותיך – חיבור לפרויקט "מחולל השיווק והתוכן"

קובץ ידע לפרויקט ב-claude.ai. מסביר לקלוד איפה מנהלים את העבודה של הצוות, ואיך מה שמייצרים בפרויקט התוכן (פוסט הפרשה, סרטונים, ניוזלטר, אתר) מתעדכן שם.

## הקישור
**https://claude.ai/artifact/CjnUchP5knm4L8EZAzWh4Z** – הדשבורד החי (ארטיפקט עם מסד נתונים משותף). כל גרסה מתפרסמת לאותו קישור; אסור לפרסם ארטיפקט חדש במקומו (המסד שייך לארטיפקט).

## כללי ברזל
- לא משנים את הקוד של הדף מתוך פרויקט התוכן. רק קוראים וכותבים במסד עם `ArtifactData` (url = הקישור למעלה).
- כל כתיבה למסמך קיים עם `if_version` של הגרסה שנקראה. לא נוגעים בשדות שלא קשורים לפעולה.
- שום דבר לא יוצא לפרסום בלי אישור מענדי בלוי (סטטוס `review` = ממתין לאישור).
- כל פעולה נרשמת במסמך אחד באוסף `activity`: `{who:'claude', text:'<מה נעשה>', at:<ISO>, itemId:<id>}`.

## מבנה הנתונים (העיקר)
- **items** – כל כרטיס. `kind`: project / content / task / event / recurring. `channel`: weekly (פוסט פרשה), video, post, newsletter, site, data, brand, admin. `status`: idea → todo → doing → review → scheduled → done.
  שדות: `title, owner, waitingOn, priority, start, due, publishAt, steps[] {t, done, owner, due, est, bg}, blocked {on, why, who}, links[], notes, platforms[]` (למשל "פייסבוק"), `thumb` (כריכה), `remindAt` (תזכורת: `YYYY-MM-DDTHH:MM`).
  `links[]` = `{label, url}` – כל קישור מוצג בחדר ככפתור עם אייקון המותג לפי הכתובת (דרייב, פייסבוק, אינסטגרם, יוטיוב, האתר...). `format` = סוג החומר של תוצר (`video` / `graphic` / `gif` / `post` / `newsletter`) – כל תוצר שיוצרים בפרויקט התוכן מקבל אותו, כדי שיופיע בקנבן "תוצרים" בשורה הנכונה. `files[]` = `{name, url, type, size, at}` – קבצים שצורפו (מהחדר בלבד; לתוצרים מהדרייב משתמשים ב-`links`).
- **people** – zalmen, mendy, ben, kaplan, tzama-social, claude. `avatar` = אווטאר מאויר; `photo` = תמונה אמיתית (קודמת).
- **inbox** – בקשות שהצוות שולח לקלוד מהדשבורד (הפקודה "הרץ את התור").
- **activity** – יומן הפעולות שמוצג ב"מה כבר נעשה".
- **agents** – מצב הסוכנים (weekly, creative, media, newsletter, site, data). המסמך `agents/_links` (`list:[{label,url}]`) = כרטיס "קישורים" של כל הצוות בדף הבית. לא נוגעים בו בלי בקשה.

## מה פרויקט התוכן עושה בחדר הבקרה
1. **פוסט הפרשה השבועי** (המשימה המתוזמנת של יום רביעי): אחרי ששומרים את התמונה והטקסט בדרייב –
   מוצאים ב-items את כרטיס הפוסט של הפרשה (`channel:'weekly'`, הכותרת כוללת את שם הפרשה). אם אין, יוצרים אחד: `{kind:'content', channel:'weekly', title:'פוסט פרשת <שם>', publishAt:<יום חמישי>, owner:'claude', platforms:['פייסבוק'], status:'review'}`.
   מעדכנים: `status:'review'`, `waitingOn:'mendy'`, מוסיפים ל-`links` את הקישור ל-Google Doc ולתמונה, ומסמנים את השלבים שבוצעו (`steps[i].done=true`).
   כריכה: לפוסט השבועי אין fal – הלוגו "תובנה" מובנה בדשבורד.
2. **כל תוצר תוכן אחר** (סרטון, ניוזלטר, פוסט): אותו דבר – כרטיס `content` בערוץ המתאים, `status:'review'` כשמוכן לאישור, קישורים ב-`links`.
3. **משימה שקלוד יכול להכין ברקע**: מסמנים בשלב `bg:true` (או `claudeCan:true` בכרטיס בלי שלבים) – הוא יופיע ב"קלוד יכול בינתיים".
4. **תזכורת לזלמן**: `remindAt` בכרטיס (או כרטיס `task` חדש עם `remindAt`). המשימה המתוזמנת "התראות תזכורות לטלפון" שולחת התראה בזמן.
5. **תמונות**: כרטיס חדש בלי `thumb` ואדם חדש בלי `avatar` מקבלים תמונה משגרת התמונות (הסקיל maayanotecha-staff-ui, `references/fal-imagery.md` סעיף 4).
