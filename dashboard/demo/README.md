# עותק הדגמה: "חדר הבקרה של סטודיו אופק"
אב טיפוס למכירה. עותק 1:1 של חדר הבקרה של מעיינותיך (גרסה 25 המאושרת), עם פרטים בדויים בלבד.

- **מה הוחלף:** שם החברה והלוגו (סימן טקסט "אופק"), שמות האנשים, התחום (פוסט הפרשה → פוסט שבועי עם "נושא השבוע", יריד → כנס), העוזר ("אטלס" במקום קלוד), הנחיות ה-AI, וכל הנתונים.
- **מה לא נגעו בו:** כל המסכים, הפונקציות, הבריף, התזכורות, ההגדרות, הרקעים, שעון החול והמד, האייקונים, האווטארים והכריכות – רק מה שכבר נוצר.
- **בלי חיבור:** מסד נתונים מקומי בדפדפן (localStorage). אין חיבור לקלוד, לחשבון או למסד של מעיינותיך. "איפוס נתוני ההדגמה" בהגדרות. הנתונים מתרעננים לבד אם עברו יותר מ-3 ימים, והתאריכים תמיד יחסיים להיום.
- **בנייה:** `python3 dashboard/demo/build_demo.py` (מתוך `dashboard/staff/v21.html`) → `dashboard/demo/opk-demo.html`. הבנייה נכשלת אם נשאר פרט אמיתי.
- **קבצים:** `demo_data.js` (הנתונים), `demo_runtime.js` (המסד המקומי), `build_demo.py`.
